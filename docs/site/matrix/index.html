x402-conformance matrix

Projects that accepted to be listed, opt-in only, in two tiers. External-verified: the checks that run from outside a project's stack against its public testnet endpoint, run by the x402-conformance run queue on each new release, with no spend. Full suite (self-hosted): the whole suite, run in the project's own CI with the Action on each release; the queue verifies its signed attestation and never runs it. Each row shows checks passed out of applicable checks, the denominator (exercised / not applicable / needs the self-hosted run, out of 79), the suite tag, the date and how the version tested lines up with the project's latest release. There is no score and no ranking. Listed projects display the badge in their own README with the line "Conformance tested by Optitransfer/x402-conformance"; both link to their row. The badge shows the tier, the suite tag, the count and the date, and turns grey when the row is stale. It is not a certification and not an endorsement. Add or update your row.
