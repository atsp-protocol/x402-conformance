Projects that accepted to be listed, opt-in only. Each row shows checks passed out of checks run and a failed count from its committed evidence, and how the version tested lines up with the project's latest release. There is no score and no ranking. Listed projects add the badge, "Tested with x402-conformance · Optitransfer", to their own README with the line "Conformance tested by Optitransfer/x402-conformance"; both link to their row. The badge shows the version tested and turns grey when the row is stale. It is not a certification and not an endorsement. Add or update your row.
