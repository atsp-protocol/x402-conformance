# Spec traceability

Generated by `tools/traceability.py` from the check catalogue (`src/x402conf/spec.py`) and the spec anchors in `docs/check-ids.json`. Do not edit it by hand: run `python3 tools/traceability.py`; CI runs it with `--check`.

Every check is in one of two classes. A **normative** check tests a MUST or SHOULD clause of the x402 V2 specification or one of its extensions, and its row names the pinned spec lines the clause is quoted from. A **hardening** check tests safety beyond what the spec requires, and its row gives the reason. This answers how much of the spec the suite tests with a count per class, not a percentage. What each check does and what it catches is in [COVERAGE.md](COVERAGE.md).
